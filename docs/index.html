How to run Grab Bag

Get a living-room game on a TV, with phones as controllers. This page is for a downloaded Grab Bag binary. You do not compile anything to host a room.

You are the person with the PC. Everyone else only needs a phone browser. Follow the sections in order the first time. Use the table of contents later when you only need one answer. You can open this file from disk, or from the running host at http://127.0.0.1:8654/docs.

What you need

  • A Windows computer that stays on for the whole party. That machine runs Grab Bag. Closing the window ends the room.
  • A TV, projector, or a second window for the board. That is the screen the room watches.
  • Phones or tablets on the same Wi-Fi as the computer. Guest Wi-Fi often blocks this. Use the house network.
  • An admin password you are about to pick. You will type it on setup, and once more on the first phone that should run the room.

Start the program

  1. Double-click the Grab Bag program. On Windows that is usually grabbag.exe.
  2. Leave the black console window open. That window is the server.
  3. If Windows Firewall asks, allow Grab Bag on a private network.
  4. In a browser on this computer, open the address the console printed. It looks like http://127.0.0.1:8654.
You should see either first-time setup, or the board if you already finished setup on this PC.
Grab Bag always uses port 8654. If another copy is already running, this one prints an error and exits. Close the other window, then start again.

127.0.0.1 only works on the machine running Grab Bag. Phones use a different URL. You will see it on the board, next to the QR code.

First-time setup

The first visit on this computer opens /setup.

  1. Pick a password of at least 8 characters. This is not a player nickname. It unlocks Room settings and lets a phone claim host. There is no "forgot password" in the binary yet. Write it down.
  2. Type it again to confirm.
  3. Leave the other boxes on their defaults for a living-room night. Seat cap 8 is plenty. Advertised hostname should stay blank unless you are putting the room on the public internet through a tunnel. Logging can stay off.
  4. Tap Finish.
You should see the board. This browser stays signed in for 30 days.

You can change the extra boxes later under Settings.

Put it on the TV

  1. On the host computer, open http://127.0.0.1:8654/board.
  2. Fullscreen that tab. F11 works in most browsers.
  3. Plug the PC into the TV, or cast that window.
You should see a QR code and a join URL on the left, and empty seats in the middle. The join URL is not 127.0.0.1. That is the address phones type if they cannot scan.

The gear in the corner opens Room settings in a new tab. You need the admin password there if this browser is not already signed in from Finish.

Join from a phone

  1. Each person opens the camera and scans the QR on the TV.
  2. They land on a "Who are you?" screen. They can reroll the cartoon face, type a name, and tap Join.
  3. The first joiner also sees a password field. The person who should run the room types the admin password, then Join. Everyone else leaves that field blank.
You should see cartoon faces appear in seats on the TV. The phone that typed the password gets a Host button. Later joiners do not see the password field once someone has claimed host.

If the board says Closed, new people cannot Join. Open the room from settings or from the Host panel. Closed locks the door. It does not kick people who are already in.

When every seat is taken, new joiners still arrive. They land in the audience and can get in line on the wait list. They watch. They do not take a seat until one frees up or you raise the seat cap.

To hand the room to someone else later, use Make host in settings. That person's phone then shows Take host and asks for the admin password.

Play a round

Do this from the claimed-host phone. The TV stays on the board so the room can watch.

  1. Confirm the board is up and the room says Open.
  2. Wait until faces are in seats. Each seated player taps Ready when they are looking at the TV.
  3. Open Host. Pick a game, then tap Load. This build ships Testing. Load mounts that package. The TV stays on the lobby. Testing is a wiring check, not a scored party game.
  4. Tap Start. Start needs at least one seated player. Some games also want a minimum table size and will refuse until enough seats are filled.
  5. Play. If you need a break, tap Pause. The round stays in memory. Resume continues it.
  6. When the round is over, tap Stop. The lobby comes back on the TV. The same game stays selected, so you can Start again without Load.
  7. Tap Shutdown only when you want to unload that game and pick a different one, or none at all.
After Start the TV and the seated phones switch into the game. After Stop they return to the lobby.

If you turn Auto-start on in settings, a full set of Ready taps can start the round for you. Leave it off until that feels natural.

The Host button

Only the claimed-host phone shows this. It is a slide-out on that device, not a menu on every phone.

If nobody claimed host at join, the next person who still sees the password field on Join can take it. After a host exists, use Make host in settings, then Take host on that phone.

Load, Start, Pause, Resume, Stop, Shutdown

These are the round controls from the previous section. Load picks the package. Start begins play. Pause and Resume freeze and continue. Stop ends the round. Shutdown unloads the package.

Sit and Stand

Sit puts someone into a seat. Stand takes them out of a seat without kicking them from the room. Use this when you want to swap who is at the table.

Kick

Removes that person from the room right now. They have to join again. Kick does not wait for any timeout.

Room settings

Opens the same settings page as the gear on the board.

Settings

Open /settings from the board gear, the Host panel, or by typing the address. Sign in with the admin password if this tab is not already signed in.

You can ignore most of this on night one. The table is for the labels people stare at and guess wrong.

Label What it does
Room Open or Closed Open lets new phones Join. Closed shuts the door. People already in keep playing.
Auto-start When on, a full set of Ready taps can start the loaded game without a tap on Start. Leave it off until that feels natural.
Seat cap How many people get a face on the table. Default 8. Range 1 to 64. Audience can still watch when the table is full.
After a game Stop leaves sitters in place. Empty seats fill from the wait list when the room is open. A full table does not rotate. Use Cycle seated players on Settings when you want the next people in line at the table.
Fill empty seats Off by default. When on, a free seat during a round can go to someone waiting. When off, the current table stays frozen until Stop.
Disconnected after Seconds of silence before Grab Bag treats a phone as gone. They still own the seat for a while. The face dims.
Kick timeout While a round is running, a dropped seated phone keeps the chair. After the round, if they still have not come back, Grab Bag removes them once this many extra seconds have passed. Set 0 to never auto-drop.
Seat disconnected waiters When on, someone who was only in line and then dropped off can still be pulled into a seat. Leave it off unless you mean that.
Protect host When on, a claimed host whose phone goes quiet is not auto-removed after Kick timeout. Operator Kick still works. Default is on.
Admin-only board When on, a random tab that opens /board without signing in does not see the roster. Use this if the TV URL might leak. The signed-in operator tab still works.
Auto-pause on seated disconnect When on, a seated phone dying pauses the game so you can wait. Audience disconnects do not pause. You can Resume while they are still gone.
Advertised hostname Leave blank for a LAN party. The board then shows the IPv4 Grab Bag found at start. Fill this in only when you publish the room through a tunnel. A Cloudflare hostname is the usual case. Phones must be able to reach that name on port 8654.
Log to stdout / host.log Stdout is the console window. host.log is a file next to the database. The Game log page is a live tail of those lines. Off is fine for a party.
Game Settings After Load, extra checkboxes for that game appear here.
Clear game data Wipes that game's saved options. It does not wipe seats, names, or host.log.
Make host Marks another seated person. Their phone then shows Take host and asks for the admin password.
Log out Signs this browser out of admin. Other signed-in phones stay signed in.

If you quit and come back

Closing Grab Bag does not forget the room. The next start reloads names and seats from disk.

  1. Start the program again.
  2. Open the board.
  3. Tap Keep this room to restore last night's table, or Clear room for a fresh house.
Until someone taps one of those you cannot Load or Start. That pause is on purpose so a crash does not dump eight people on the floor.

Files live in the user cache, in a folder named grabbag. On Windows that is %LOCALAPPDATA%\grabbag. You will see host.sqlite, maybe host.log, and a games folder per game id. An older Hackbox install kept the same files under %LOCALAPPDATA%\hackbox. This build does not read that folder.

Phones cannot join

Work down the list. Most nights it is Wi-Fi or the wrong URL.

  1. Confirm the phone and PC are on the same Wi-Fi. Not a guest network. Not cellular.
  2. Confirm Windows Firewall allowed Grab Bag on that private network.
  3. On the phone, use the URL or QR on the board. Do not type 127.0.0.1. That address means "this device," so the phone would look for Grab Bag inside itself.
  4. Confirm the board says Open.
  5. If you set advertised hostname, that name has to reach this PC on port 8654 from the phone.

Stop Grab Bag

Close the console window, or press Ctrl+C in it. There is no tray icon in this build.

Starting the program again brings the last room back until you Keep or Clear it.
